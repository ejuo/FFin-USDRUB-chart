# USD/RUB: Freedom Bank и USDRUBF

Адаптивный статический сайт для внутридневного сравнения:

- курса покупки и продажи USD/RUB в мобильном приложении Freedom Bank;
- часовых свечей вечного фьючерса `USDRUBF`, страницу которого показывает РБК Quote.

Цель — найти день и час, когда разрыв между биржевым ориентиром и курсом исполнения в приложении минимален.

## Что умеет интерфейс

- периоды **24 часа**, **7 дней**, **2 недели**, **месяц** и произвольный диапазон с точностью до времени;
- часовая шкала и непрерывное отображение рыночной линии; перерывы торгов соединяются отдельным пунктиром;
- точные значения по наведению, касанию, клавишам стрелок и в закреплённом инспекторе под графиком;
- топ-3 лучших часов в выбранном периоде для двух операций:
  - купить USD у Freedom: `Freedom sell − USDRUBF`;
  - продать USD Freedom: `USDRUBF − Freedom buy`;
- маркеры лучших часов на графике и часовая таблица синхронных наблюдений;
- хранение до 190 дней данных.

## Частота обновления

Freedom Bank не публикует фиксированный регламент изменения валютного курса. На официальной странице указано только, что курс может меняться в течение дня. Поэтому workflow выполняет независимый замер **каждый час в 17-ю минуту**. Минута выбрана не на границе часа, поскольку GitHub предупреждает о возможных задержках scheduled workflows в периоды пиковой нагрузки в начале часа.

Публичная таблица CreditBureau содержит время `Актуально`. Сборщик сохраняет и время наблюдения, и время обновления источника, поэтому после накопления истории можно будет эмпирически оценить фактическую частоту изменений курса.

## Откуда берутся данные

Сборщик сначала читает прямую мобильную пару `USD/RUB` из публичной таблицы CreditBureau. При её недоступности он рассчитывает резервный кросс из официальных мобильных курсов Freedom Bank:

```text
Freedom покупает USD/RUB = USD/KZT покупка ÷ RUB/KZT продажа
Freedom продаёт USD/RUB = USD/KZT продажа ÷ RUB/KZT покупка
```

У банковских точек есть поле `method`:

- `direct` — точная строка `USD / RUB`;
- `derived-cross` — оценка через `USD/KZT` и `RUB/KZT`.

Часовые OHLC-свечи `USDRUBF` загружаются через MOEX ISS с `interval=60`. В момент каждого сбора сохраняется отдельная синхронная точка: текущий курс Freedom плюс последнее доступное значение часовой свечи. Сравнение не создаётся, если рынок закрыт и свежей свечи нет.

## Формат данных

`data/rates.json`, schema version 2:

- `freedom` — все ежечасные наблюдения банковского курса, включая часы без изменения;
- `market` — часовые свечи USDRUBF;
- `comparisons` — синхронные ежечасные наблюдения, по которым рассчитываются лучшие часы;
- `meta` — часовой пояс, период хранения и частота сбора.

Старые дневные точки schema version 1 автоматически мигрируют при первом запуске сборщика.

## Важно о сравнении

`USDRUBF` — биржевой вечный фьючерс, а не банковский курс обмена. Он используется как рыночный ориентир; банк не обязан проводить обмен по цене фьючерса. Для принятия решения следует смотреть отдельно направление покупки и направление продажи USD.

## Локальный запуск

Требуется Node.js 22+.

```bash
npm run check
npm run build
python3 -m http.server 8000 -d _site
```

Затем открыть `http://localhost:8000`.

Обновление данных вручную:

```bash
npm run update
```

## Публикация

Workflow `Deploy GitHub Pages` публикует сайт после изменения ветки `master`. В настройках репозитория нужно один раз выбрать **Settings → Pages → Source → GitHub Actions**.
